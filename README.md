# Janeses Integrated Services Ltd: website

Upload these to your host: `index.html about.html services.html portfolio.html contact.html`, and the folders `css/ js/ images/ downloads/`.
Do NOT upload `images-src/`, `src/`, `tools/` (they are your working files).

## Before launch (5-minute checklist)
1. `js/script.js` -> CONFIG: paste a form-service URL into `leadEndpoint` (collects kit emails) and `inquiryEndpoint` (contact form). Free options: Formspree, Getform, Google Apps Script. Until then: the kit still downloads, but emails are NOT saved, and the contact form opens WhatsApp with the details filled in.
2. `tools/build-site.py` -> change `SITE` to your real domain, confirm `PHONE_2`, then run it again.
3. Replace the sample testimonials (index) and FAQ answers (contact) with real ones; add real photos in place of "Photo coming soon" tiles.
4. Add a Google Map embed in `src/pages/contact.html` (the `map-ph` block) and your Facebook link.

## Adding photos
1. Drop originals into `images-src/` (any size, jpg / png / webp).
2. `pip install pillow`, then `python tools/optimize-images.py`  -> WebP in `images/`.
3. Reference a photo in a page with `{{img:file-name|Describe the photo|card}}` in `src/pages/*.html`.
4. `python tools/build-site.py` rebuilds the pages. It stops with an error if a photo is used twice.

## Editing the lead magnet PDF
Edit text in `tools/build-kit-pdf.py`, run `python tools/build-kit-pdf.py` -> `downloads/janeses-event-planning-kit.pdf`. (`pip install reportlab pillow`)
